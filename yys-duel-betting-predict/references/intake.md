# 信息索要模板与解析细则

## 1. 一次性索要模板（直接发给用户）

```
我需要下面这些才能算，缺一项都会让结论不可靠（对弈面板不是常规面板，我不能凭记忆补）：

【每场必给】
- 场次时间（如 14:00）
- 红方 / 蓝方 各 5 个式神名

【每个式神给 4 行】
1) 阵容序号（界面里的 ⑤→③→②→④→① 这种；用来算群攻谁先挨打）
2) 八项面板：攻击 / 生命 / 防御 / 速度 / 暴击 / 暴击伤害 / 效果命中 / 效果抵抗
3) 佩戴御魂：套装名（标明是否成套，如"破势4+暴击2"）
4) 御魂各位置主属性（尤其 2/4/6 号位）

【有就更好】
- 双方"合计加成"那一栏的截图（用来交叉校验我抄的数字）
- 你是不是已经押了、押了多少（我据此调整风险建议）
```

## 2. 拿到截图时怎么处理

1. **先把图里的数字逐项抄成表格，回贴给用户确认**，然后再往下算。
   - 对弈面板经常是"御魂配不出来的极限数值"，抄错一位就会算错，确认一次成本很低。
2. 若某格被遮挡/看不清 → **问，不要猜**。写 `?` 并在报告里标 `⚠️ 待核实`。
3. **阵容序号**如果界面没给（只有"阵容顺序"），要明确说明"群攻顺序将按输入顺序推断，可能不准"。

## 3. 数值口径校验（抄完后先自查）

| 检查 | 判据 | 不通过时 |
|---|---|---|
| 速度 | 全场最高速者 = 一速方；合计速度更高的一方通常占优 | 若一速归属反直觉，复核是否抄错 |
| 暴击 | 输出式神 `暴击 < 100%` → 必须按 `1 + 暴击率×(暴伤−1)` 打折 | 在报告里显式写出打折后的期望系数 |
| 暴伤 | 显示值 ≥ 150% | 若 < 150% 基本是抄错（基础就是 150%） |
| 命中/抵抗 | 多为 0 / 15 / 30 … 的整十倍数 | 出现怪值就复核 |
| 御魂 | 是否成套（4+2）；是否出现首领御魂 | 首领御魂在对弈里 2 件套不生效，按"没有 2 件套"处理 |
| 攻击 vs 生命 | 单次核弹型输出：`总攻击 × 系数 × 防御系数` 是否会一击秒杀 | 若账面伤害远超对方生命，属"先手即结束"局，重点转到一速 |

## 4. 写进 `lineup.json` 的对应关系

| 界面字段 | JSON 字段 | 备注 |
|---|---|---|
| 阵容序号 | `pos`（1–5） | **必填**，群攻顺序 `4→1→2→3→5` 靠它 |
| 攻击 / 生命 / 防御 / 速度 | `atk` / `hp` / `def` / `spd` | 直接填界面数字 |
| 暴击 / 暴击伤害 / 效果命中 / 效果抵抗 | `crit` / `cdmg` / `hit` / `res` | **填百分数的数值部分**：界面 85% → 写 `85` |
| 御魂套装 | `souls` | 数组，如 `["破势","荒骷髅"]` |
| 技能 | `skills[]` | 面板换算不出技能，**去 `03B_式神技能全量.md` 查技能名/鬼火/系数** |
| 免死 / 无法被治疗 / 减伤 | `passive` | 查 `03_式神数据.md` 的卡片或 `03B` 技能原文 |

> **技能系数怎么填**：`coef` 填**技能说明里那个百分比**（598% → `5.98`），段数填 `hits`。
> 别把段数乘进系数里（曾经踩过：3 段 × 600% 写成 `coef=6.0, hits=3`，结果模拟必赢）。

## 5. 用户只问"这场怎么押"但没给阵容时

直接回上面 §1 的模板。**不要**先给一堆通用"押注技巧"再要信息——那是本末倒置，用户要的是这一场的判断。
