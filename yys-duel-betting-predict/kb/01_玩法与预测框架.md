### 1.2 赛前可见信息字段清单（唯一预测依据）

对弈竞猜界面能看到的字段（按 2026 春节实战截图与界面描述整理）：

| 层级 | 字段 | 说明 |
|---|---|---|
| 阵容层 | **红/蓝双方各 5 名式神的名字（分「阵容顺序」与「阵容序号」两种排列）** | 「阵容序号」形如 `⑤→③→②→④→①`，它给出**每个式神在阵型中的 1–5 号站位**，直接决定群攻优先命中的顺序（见 `06` §5） |
| 式神层 | **每位式神的 8 项面板**：攻击 / 生命 / 防御 / 速度 / 暴击 / 暴击伤害 / 效果命中 / 效果抵抗 | 这是「该式神的实际对弈面板」，非官网基础值、非普通御魂面板，见 §2.4 |
| 式神层 | **所佩戴御魂**：套装名（含 2 件套 / 4 件套是否成套）+ 各位置**主属性** | 判断「输出式神是否满暴」「辅助是否带火灵/招财/蚌精」的关键 |
| 队伍层 | **双方「合计加成」列表**：攻击 / 生命 / 防御 / 速度 / 暴击 / 暴击伤害 / 效果命中 / 效果抵抗 各自的总量对比 | 例：`速度→651 < 796`，一眼看出**谁是一速方**；`效果抵抗→304% < 335%` 看出**谁的抗性更低** |

> **⚠️ 待核实**：当前（十周年特别版）界面是否**逐条列出御魂副属性**，以及是否显示「御魂总加成」的明细。历史界面只保证能看到**套装 + 主属性**；副属性是否完全公开存疑。**下注时请以你眼前这一局的实际界面为准。**

> **实操含义**：界面给的是**结果**（谁是几速、谁抗性低、谁暴击没满），不是**过程**。所以预测的本质是——把这 10 张面板，还原成一场自动战斗的推演。

### 1.3 结算判定

1. **正常分出胜负**：一方全灭 → 另一方胜。
2. **裁决机制**（斗技战场通用）：战场中存在不可选中的 **裁决鬼王**，它每行动 1 回合，双方各 +1 层「**裁决之力**」：`造成伤害 +15%`、`治疗量 −10%`；裁决鬼王行动到**第 11 回合**起进入「**究极之刻**」，造成伤害增加由 15% 上升到 **30%**（治疗削减不变）。**段位越高，裁决鬼王行动越快。**
   - ⭐ **对弈竞猜适用同一套裁决机制——已确认**：网易大神《揭秘对弈竞猜》原文第 4 条明确写「**和斗技一样，对弈中也会随时间叠加增伤减疗 buff**」。因此 `06` §4.1 的战略推论（越长局越利输出、纯奶必崩）**在长局里是决定性的**。
   - ⚠️ 待核实：对弈中裁决鬼王的**行动速度**是否与斗技段位联动（对弈无段位概念，可能固定）。
3. **平局兜底**：若时间耗尽仍未分胜负 → 先按「**存活式神数量多者胜**」，再按「**双方存活式神剩余生命总和更高者胜**」。
4. **特殊判负**：出现「**场上只存在余烬**」这类明确写为「视为战斗失败」的状态时，直接判负（例：SP 百羽凤凰火）。

| 形态 | 内容 | 结论性质 |
|---|---|---|
| 早期（2017 起） | 勾玉档位：**10 / 20 / 60 / 100 / 200**。押中给对应奖励；押错不返还；**无论胜负，押注的勾玉都不返还**（= 用勾玉换奖励） | 【官方文案】 |

> **⚠️ 绝不采信的信源**：网络上关于对弈竞猜的「内部数据/隐藏规律」类内容（如「11:00–13:00 场次最容易爆冷」「带新皮肤上场有 15% 攻击加成」「系统凌晨 4 点重置胜率参数」等）**均为编造**，无任何官方或可靠实测支撑，本库一律不收录、不引用。

| **A. 官网式神录基础显示值** | 官网 `yys.163.com/shishen/608.html` 的「觉醒前 / 觉醒后」括号值 | 觉醒前 攻 172 / 生 1096 / 防 86 / 速 110；觉醒后 攻 185 / 生 1202 / 防 94 / **速 120** | 只用于横向比较式神成长倾向、看觉醒增幅 |
| **B. 游戏内 6 星满级面板** | 式神升到 6 星 40 级的实际基础面板 | 攻击 3899 / 生命 12840 / 防御 551 / 速度 120 / 暴击 10% / 暴伤 150% | 计算总攻击、总防御的**白字**基础 |
| **C. 对弈竞猜实际面板** | **对弈式神不使用普通御魂，而是「百鬼弈加点器」加点生成** | — | **唯一该用来做预测的面板**，界面直接给出 |

**口径 C 的关键机制**（NGA 实测揭露，2022 年帖）：

- 百鬼弈**每加 1 点**的加成：攻击 `+6%`、生命 `+5%`、防御 `+7%`、速度 `+6`（固定值）、暴击 `+5%`、暴击伤害 `+7%`、效果命中 `+6%`、效果抵抗 `+8%`。
- 所有式神**默认自带**一套基础加成：攻击 `+486`、生命 `+2053`、防御 `+104`。
- **标准分配点数 50 点**，但**实际不守恒**：实测 千姬 ≈16 点、鬼吞 ≈35 点、鸦天狗 ≈72 点、跳跳妹妹/雪童子 ≈81 点。
- **推论**：对弈面板里那些**用正常御魂根本配不出来的极限数值**，来自加点器；加点数越多 ≈ 策划认为该式神越「需要补强」。这对「凭面板估强弱」有直接指导意义。

## 4. 预测决策框架（可照着走的清单）

> 使用方式：**从上往下逐项打勾**，任何一步出现「明确判负信号」就直接给出结论；走到最后仍无定论，就**如实写「五五开 / 不压」**。禁止强行给结论。

### 第 0 步：先算「能不能打出来」——鬼火与节奏

- [ ] **数耗火单位**：数双方各有多少个「放技能才有效」的 2–3 火单位。
- [ ] **数供火来源**：火灵 / 招财猫 / 座敷童子 / 辉夜姬 / 追月神 / 千姬 / 薰 / 缘结神 / 神无月（幻境回火）。
- [ ] **判缺火**：缺火队伍即使账面输出高，也会全程普攻 → **直接判负**。
- [ ] **看一速归属**：界面「合计加成」里的**速度**谁高？谁是全场一速？谁有拉条（山兔 / 镰鼬 / 久次良 / 妖琴师）？
- [ ] **口诀校验**：`3 火拉条 + 3 火供火 + 2 火输出 = 开局刚好 8 火`，属「标准启动」。
- [ ] **对弈专属**：**对弈竞猜开局为 4 点鬼火**（不是 3 点，见 `06` §3）；带火灵再 `+3`（**多套火灵只生效一套**）；带座敷童子先机再 `+3`（**多个座敷可叠加**）。

### 第 1 步：再看「打得准不准」——命中与控制链

- [ ] 关键控制在自动战斗下能否连上：`命中率 = 基础概率 × (1 + 效果命中)`，再 `÷ (1 + 效果抵抗)`；命中率**封顶 100%、下限 1%**。
- [ ] 看清控手段：驱散 / 解除 / 庇护 / 免疫。**被控方有没有自救**？
- [ ] 记牢三分法：**软控可驱散、硬控只能解除、印记型谁都解不掉**（可被「庇护」免疫的是印记类**控制**，印记类**减益**不可）。
- [ ] 多段控制对高抵抗压制更强：`1 − (1 − p)^n`，别被「高抵抗」吓退。
- [ ] **比对双方的「效果命中」与「效果抵抗」合计**——这是界面里最值得看的一栏。

### 第 2 步：再看「打得多不多」——输出与御魂契合

- [ ] 输出式神**是否满暴**（暴击合计 ≥ 100%）？**未满暴则暴伤属性近乎归零**。
- [ ] 御魂是输出套还是错配？多段 → 针女；单段高倍率 → 破势 / 海月火玉；长线 → 狂骨 / 心眼 / 伤魂鸟。
- [ ] **警惕「演员」**：式神名气大但御魂/面板不匹配 → 实际表现远低于名气。**对弈竞猜最忌讳「只看式神名气」。**
- [ ] 增伤 / 减伤 / 治疗量都是**独立乘区**：堆一个不如叠乘区。

### 第 3 步：再看「活得久不久」——生存与容错

- [ ] 治疗 / 护盾 / 复活 / 免死 / 反伤（镜姬、地藏像、磐长花、余烬、蝉翼）。
- [ ] 治疗与护盾**也吃暴击暴伤** → 判断「能不能扛住」按**期望值**算。
- [ ] 有没有能**拆盾**的人？**针女与控制类御魂必须「对血量造成伤害」才触发 → 打在护盾上无效**（蚌精 / 磐根之佑 / 羽茧 / 蝉翼 直接废掉针女与魅妖/雪幽魂/日女巳时这类控制御魂）。
- [ ] 有没有**无视护盾/免死**的手段（例：茨木童子 `处决` 伤害不被吸收/免疫/分摊；部分技能写明「不触发敌方御魂」）。

### 第 4 步：再看「拖下去谁赢」——裁决之力

- [ ] 双方都会随时间增伤、治疗量衰减；**第 11 回合起增伤翻倍（+30%）**。
- [ ] → **拖后期的受益方是「输出位还活着、且有斩杀手段」的一方**；纯肉/纯奶阵容在后期必然崩。
- [ ] → 先判断「**这局大概打几回合**」：速攻阵容（双拉 + 一速爆发）通常 < 5 回合结束，此时裁决之力几乎不产生影响；肉/奶/反手阵容常拖到 10+ 回合，裁决之力成为**胜负手**。

### 第 5 步：兜底——平局怎么算

- [ ] 时间耗尽 → **存活数多者胜** → 再比**存活者剩余生命总和**。
- [ ] 推论：**「活得多的那一方」往往赢在最后的拉锯**；带复活/免死/多单位召唤的一侧在平局判定上占优。

### 第 6 步：把结论写成决策

- [ ] 输出：**推荐方 + 主要理由（1–2 条最硬的）+ 最大不确定性（通常来自 AI 行为与随机概率）**。
- [ ] 明确区分两种结论：
  - **高置信判断**：如「一方既有一速、又有拉条、还多一个供火位，且另一方缺火」。
  - **五五开、建议不压**：双方各有硬伤、或关键控制概率在 50% 上下摇摆。
- [ ] 记录赔率与「冷门 / 翻盘」的期望收益，但**不鼓励高风险重注**。
- [ ] 保留「**这局无法判断**」的结论。**禁止强行给结论。**
