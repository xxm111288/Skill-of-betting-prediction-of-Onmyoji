## 1. 八大属性的实际含义

对弈竞猜界面对每位式神给出 8 项数值，它们就是「合计加成」列表里那 8 栏的明细。

| 属性 | 含义 | 在对弈竞猜里的实际作用 | 结论性质 |
|---|---|---|---|
| **攻击** | 面板攻击。技能的伤害系数按**总攻击**放大 | 输出式神的**第一乘区**；但「攻击高 ≠ 打得多」，还要乘暴击、暴伤、增伤 | 【官方文案】 |
| **生命** | 面板生命。承受伤害的池子 | 决定**能被几刀砍死**；也是护盾量/治疗量（部分式神按生命上限结算）的基数、平局判定的第二顺位比较项 | 【官方文案】 |
| **防御** | 面板防御。进入伤害公式的减伤项 | 见 §2「防御减伤」；**边际收益递减**，且**可以被减到负值**（负防反而增伤） | 【社区共识】 |
| **速度** | 面板速度。决定行动条初始位置 | **对弈竞猜里权重极高**：先手方可以无代价地控住/秒掉后手方的核心 | 【官方文案】 |
| **暴击** | 暴击率。决定是否打出暴伤 | **未满暴 = 暴伤属性近乎归零**（见 §2「暴击期望」）；界面上「暴击」一栏要跟 100% 比 | 【社区共识】 |
| **暴击伤害** | 暴击时的伤害倍率。基础 150% | 只有**暴击之后**才生效；满暴前堆暴伤是**无效投资** | 【官方文案】 |
| **效果命中** | 提升「基础概率」的系数 | 只作用于**由数值判定命中**的减益/控制；**不影响驱散**（驱散固定概率，不吃命中） | 【官方文案】/【社区共识】 |
| **效果抵抗** | 削弱「命中率」的系数 | **只在命中判定成功后才结算**；不影响驱散 | 【官方文案】 |

> **易错点 1**：**速度相同时行动顺序随机**（斗技双方同速时实测如此）。所以「合计速度」完全相同 = 一速归属**不可预测**。
> **易错点 2**：**所有显示数值均四舍五入**（含基础面板）。界面上的速度 120 可能是 119.6。

## 2. 公式总表（每条含适用边界与反例）

### 2.1 防御减伤

$$
\text{实际伤害} = \text{原伤害} \times \frac{300}{300 + \text{防御}}
$$

| 项 | 说明 |
|---|---|
| **适用边界** | 仅用于**普通伤害的防御乘区**；对**真实伤害 / 间接伤害 / 传导伤害**不适用（真实伤害无视防御）。 |
| **推论 1** | 每 **+300 防御**，需要**翻倍**原伤害才能抵消。 |
| **推论 2** | 防御**可被减到负值**；负防时 `300/(300+负值) > 1`，**反而增伤**（这就是为什么「减防」在对弈里有意义）。 |
| **反例 / 易错** | ⚠️ 误把「无视防御」当成「无视减伤」：网切类效果只少算防御，**不减伤区仍然生效**。 |

### 2.2 命中判定（两段判定）

$$
\text{命中率} = \text{基础概率} \times (1 + \text{效果命中}), \qquad
\text{实际命中} = \frac{\text{命中率}}{1 + \text{效果抵抗}}
$$

| 项 | 说明 |
|---|---|
| **适用边界** | 仅适用于「**以基础概率触发**的减益/控制」。对**固定概率效果无效**（例如驱散固定 100%/67%，**不受命中与抵抗影响**）。 |
| **封顶与下限** | 命中率**最高 100%、最低 1%**。 |
| **判定顺序** | **先判命中，再判抵抗**；抵抗**只在命中判定成功后结算**。 |
| **反例 / 易错** | ⚠️ 把抵抗当成「独立的一次豁免」：错。命中率封 100% 后，抵抗仍能把它压下去；反过来，「命中率下限 1%」意味着**再高的抵抗也无法做到 100% 免疫**。 |
| **对弈用法** | 界面里「效果命中」「效果抵抗」两栏就是要塞进这个公式算真实命中率。 |

### 2.3 多段控制

$$
P(\text{至少命中 1 次}) = 1 - (1 - p)^n
$$

| 项 | 说明 |
|---|---|
| **符号** | `p` = 单段实际命中率；`n` = 段数 |
| **适用边界** | 适用于**每段独立判定**的多段技能。若技能写的是「首次命中后附加」则**不适用**。 |
| **反例 / 易错** | ⚠️ 不要用 `n × p` 估算（会超过 100%）。例：`p=0.3, n=3` → 真实值 `1−0.343=65.7%`，而非 90%。 |
| **对弈含义** | 多段技能**对高抵抗目标的压制明显更强**；这就是「多段控制」在自动战斗里比单段控更值钱的原因。 |

### 2.4 总攻击

$$
\text{总攻击} = \text{基础攻击(白字)} \times (1 + \text{攻击加成}\%) + \text{御魂固定攻击}
$$

| 项 | 说明 |
|---|---|
| **适用边界** | **百分比加成只作用于白字**；御魂 1 号位的**固定攻击**不吃百分比。 |
| **面板逆向** | 若已知总攻击与加成，可反推白字，用于验证界面数值是否被四舍五入。 |
| **反例 / 易错** | ⚠️ 「固定攻击也吃加成」是常见错误理解，会让估算偏高。 |

**对弈专属提示**：对弈式神的面板来自**百鬼弈加点器**（不是御魂），其基础加成是 攻 `+486` / 生 `+2053` / 防 `+104`，再按点数叠加（攻击每点 `+6%`）。所以不要再按「6 个御魂」的模型去反推对弈面板。

### 2.5 总防御

$$
\text{总防御} = \text{基础防御(白字)} \times (1 + \text{防御加成}\%) + \text{御魂固定防御}
$$

| 项 | 说明 |
|---|---|
| **适用边界** | 同上，百分比只作用于白字；3 号位固定防御不吃加成。 |
| **反例 / 易错** | ⚠️ 「减防」类效果作用于**总防御**，因此**先堆防御的一方被减防时损失更大**。 |

### 2.6 最终伤害（乘区总式）

$$
\text{最终伤害} = \text{总攻击} \times \text{技能系数} \times \text{暴击修正} \times \text{防御受伤系数} \times \text{增伤区} \times \text{减伤区} \times \text{御魂修正} \times \text{技能修正}
$$

其中：

$$
\text{防御受伤系数} = \frac{300}{300 + \text{总防御}}, \qquad
\text{减伤区} = \frac{1}{1 + \text{减伤}}
$$

| 项 | 说明 |
|---|---|
| **适用边界** | 适用于**普通伤害**。真实伤害跳过防御项；间接伤害（毒/传导）另有规则；部分技能写明「不触发御魂/被动」时，**御魂修正区直接省略**。 |
| **性质** | 各乘区**相互独立** → **叠乘区**（如同时有增伤 buff 与减防 debuff）收益远大于堆单一乘区。 |
| **反例 / 易错** | ⚠️ 把「增伤」和「减防」当同一类：错。前者乘在增伤区、后者改防御受伤系数。 |
| **对弈含义** | 判断输出强弱至少要看到 **攻击 × 暴击期望 × 增伤 × 御魂** 四块，只报攻击面板是耍流氓。 |

### 2.7 减伤

$$
\text{受到伤害} = \frac{\text{原伤害}}{1 + \text{减伤}}
$$

| 项 | 说明 |
|---|---|
| **适用边界** | 与「效果抵抗」同构（除法而非减法）。 |
| **反例 / 易错** | ⚠️ **「100% 减伤」也只减半**（`1/(1+1)=0.5`），不是免疫。想真正扛住必须靠**护盾 / 免伤 / 免死**这类明确写「免疫伤害」的效果。 |
| **对弈含义** | 面板上「减伤 30%」「减伤 60%」的实际收益远低于字面直觉。 |

### 2.8 暴击期望

$$
\text{期望伤害} = \text{总攻击} \times \left[ 1 + \text{暴击率} \times (\text{暴击伤害} - 1) \right]
$$

| 项 | 说明 |
|---|---|
| **适用边界** | 用于**多次攻击的期望**估值。单次高倍率技能仍应按「是否暴击」两分支评估。 |
| **反例 / 易错** | ⚠️ **未满暴时暴伤属性近乎失效**：若暴击率 50%、暴伤 300%，期望系数只有 `1+0.5×2=2.0`，而满暴时为 `3.0`。所以在对弈里看到「暴击 60% / 暴伤 300%」的输出，实际比「暴击 100% / 暴伤 220%」弱。 |
| **对弈用法** | 界面「暴击」一栏 **< 100% 就按上式打折**，这是识破「假输出」的第一把尺子。 |

### 2.9 治疗与护盾

| 规则 | 内容 | 结论性质 |
|---|---|---|
| 吃暴击 | **治疗与护盾数值受暴击、暴伤加成影响** | 【玩家实测】 |
| 不波动 | 治疗和护盾数值**固定不波动**（普通伤害才有 99%–101% 的波动） | 【玩家实测】 |
| 例外 | 黑童子普攻伤害波动 80%–120%；彼岸花花海伤害无波动（常用于测怪物防御） | 【玩家实测】 |
| **对弈含义** | 判断「能不能扛住」必须按**期望治疗量/期望护盾量**算，不能只看技能系数 | — |

> ⚠️ 待核实：治疗/护盾的暴击是否沿用同一套 `暴击修正`（应为「暴击时按暴伤倍率放大」），各来源表述不一，本库按「同规则」处理。

### 2.10 间接伤害 / 真实伤害 / 传导（判定关键）

| 类型 | 是否吃防御 | 是否触发御魂 | 是否触发被动 | 备注 |
|---|---|---|---|---|
| **普通伤害** | 是 | 可触发（视御魂条件） | 可触发 | 有 99%–101% 波动 |
| **真实伤害** | **否** | 通常**不触发**（技能写明） | 视技能 | 例：针女追加伤害被明确描述为「真实伤害」 |
| **间接伤害** | 按技能描述 | 通常**不触发** | 视技能 | 例：淬火、蛛毒、深眠的回合前伤害、冰花的激发伤害 |
| **传导伤害** | 视技能 | 视技能 | 视技能 | 常见「传导」用于绕过护盾类规避 |

> **对弈含义**：**「不触发御魂」是对弈里的强力标签**。它意味着敌方的**木魅（扣火）、返魂香（反控）、地藏像、镜姬（反伤）**都失效。

### 2.11 单次伤害的结算顺序（⭐ 乘区先后决定收益）

> 完整版（14 步，含薙魂 / 白藏主 / 薰 / 免死分叉）见 `04_机制词条.md` §14，此处只给**够用的简化七步**。

$$
\text{伤害基础量} \to \text{增伤结算} \to \text{防御结算} \to \text{暴击结算} \to \text{御魂结算} \to \text{承伤结算} \to \text{特殊技能结算}
$$

| 项 | 说明 |
|---|---|
| **「承伤结算」是什么** | **易伤（承受伤害增加）** 与 **承伤降低** 在此步生效；代表：丑时之女咒火、以津真天黄金羽、晴明「符咒·生」 |
| **易伤的位置** | **在防御结算之后** → `伤害 × (1 + 易伤)`。所以**高防目标吃易伤，收益完全不打折**；反过来算「减防 vs 易伤」时，两者**不是同一乘区** |
| **承伤降低是倒数** | 承伤降低 30% → `÷ 1.3 = ×0.769`，**不是 ×0.7**（与 §2.7 减伤同构） |
| **适用边界** | 仅针对**直接伤害**。间接伤害**无法分担**，格式与触发规则另计（`04` §13.2） |
| **反例 / 易错** | ⚠️ 把「易伤」和「减防」当成同一个东西 → 会把两者叠加算成 60% 而实际是 `1.3 × 1.43 ≈ 1.86` |
| **对弈含义** | 以津真天 3 层黄金羽（**减疗+易伤各 60%**）之所以是全版本最强辅助之一，就是因为**易伤与减防双乘区叠加** |

### 2.12 「治疗」与「恢复」是两套体系（直接影响减疗的判定）

| 概念 | 吃暴击 / 暴伤 | 受减疗影响 | 触发治疗相关效果 |
|---|---|---|---|
| **治疗** | ✅ | ✅ | ✅ |
| **恢复** | ❌ **不吃** | ❌ **不受影响** | ❌ **不触发** |
| **吸血** | ❌ 不吃 | ❌ 不受影响 | ❌ 不触发 |
| **失去生命** | — | — | —（不是伤害，**护盾挡不住**） |

| 项 | 说明 |
|---|---|
| **适用边界** | 判断「减疗能不能压住这个奶」时，**先看技能写的是「治疗」还是「恢复」**。 |
| **反例 / 易错** | ⚠️ 误以为**减疗（含裁决之力的减疗）能压死所有续航**：**千姬 / 蝎女 / 鬼王酒吞 / 匣中少女「回梦」等「恢复系」完全不吃减疗**。 |
| **推论** | **长局里「恢复系」续航比「治疗系」更耐打**；反过来，**只有暴击收益的治疗（如萤草、花鸟卷）才是「满暴 = 满奶」**。 |
| **推论 2** | 治疗与护盾**都吃暴击/暴伤**（`暴击后治疗量 = 原治疗量 × 暴伤`）；唯一的例外细节是**惠比寿的鲤鱼旗不继承暴击**，但**加了暴击 buff 后旗子的治疗照样能暴击**（社区实测） |

> 【官方蓝字词条 + 网易大神实测】置信度：中高（两来源一致，官方词条原文见 `04` §13.3）。

## 3. 御魂数值规则

### 3.1 主属性池

| 位置 | 固定/可选 | 可选池 |
|---|---|---|
| **1 号位** | 固定 | **固定攻击**（数值） |
| **2 号位** | 可选 | 速度（固定值）/ 攻击% / 防御% / 生命% |
| **3 号位** | 固定 | **固定防御**（数值） |
| **4 号位** | 可选 | 效果命中 / 效果抵抗 / 攻击% / 防御% / 生命% |
| **5 号位** | 固定 | **固定生命**（数值） |
| **6 号位** | 可选 | 暴击 / 暴击伤害 / 攻击% / 防御% / 生命% |

> 【官方/官网攻略口径一致】【结论性质：官方文案】
> **对弈含义**：看到某输出式神 **6 号位是「攻击%」而不是「暴击/暴伤」**，就基本可以判定它**没满暴 → 输出要打折**。

### 3.2 副属性成长区间

| 副属性 | 单次成长区间 |
|---|---|
| 攻击 / 生命 / 防御（数值） | 攻击 24–30；生命 92–115；防御 4–5 |
| 攻击% / 生命% / 防御% / 暴击伤害 / 效果命中 / 效果抵抗 | **3.2% – 4.0%** |
| 暴击 | **2.4% – 3.0%** |
| 速度 | **2.4 – 3.0** |

> 【官方/百科口径】【结论性质：官方文案】
> **对弈含义**：**暴击的成长区间比暴伤小**（3% vs 4%），所以「满暴 + 高暴伤」很难同时达成，看到两者都极高就要警惕是不是**加点器给的面板**。

### 3.3 强化规则

- 御魂每升 **3 级**（3 / 6 / 9 / 12 / 15）获得一次随机强化：**未满 4 条副属性时新增 1 条**；**已满 4 条时随机强化其中 1 条**。
- **每个御魂最多 4 种副属性。**
- **星数 = 额外强化次数**：星数越高，同等级已被强化次数越多。
- **强化等级可无损转移**：`+3` 御魂作为材料强化另一个 `+0` 御魂 → 得到 `+3`；但 `+6` 作为材料强化 `+0` → 只得到 `+5`（**3 级以上经验流失**）。
- 主属性提升幅度：数值型每次约 +20%（取整，最低 +1）；**百分比型每次固定 +1%**。

> 【官网/百科】【结论性质：官方文案】

### 3.4 首领御魂的固有属性

- 首领御魂的**固有属性**从 `攻击加成 8% / 生命加成 8% / 防御加成 16% / 暴击 8% / 效果命中 8% / 效果抵抗 8%` 中**随机生成**，携带即生效。
- **多套不同的 2 件套效果可叠加；相同的多套 2 件套不叠加（唯一被动）。**
- **首领御魂的 2 件套效果仅在与「怪物」战斗时生效**（探索 / 觉醒 / 御魂 / 石距 / 年兽 / 秘闻 / 地域鬼王 / 真·八岐大蛇等）。

> 【官方文案，2018 官方公告】
> **⚠️ 对弈竞猜的关键推论**：对弈竞猜的对手是**式神**，不是怪物。所以 **荒骷髅 / 土蜘蛛 / 胧车 / 地震鲶 / 蜃气楼 / 鬼灵歌伎** 这类首领御魂的 2 件套被动**在对弈里基本不生效**（只能吃到 8 点固有属性）。因此在对弈界面看到有人带首领御魂，**应按「接近没有 2 件套」处理**——这是一个非常容易踩的坑。
> ⚠️ 待核实：`片叶之苇` 等较新御魂的定位与是否属首领系；**未找到可靠信源，待核实**。

## 4. 行动条与速度的数学

> 完整机制见 `06_战斗流程与AI行为.md` §1，此处只列公式。

$$
\text{初始位置} = \frac{\text{自身速度}}{\text{全场一速}} \qquad (\text{例外：白藏主})
$$

$$
\text{拉条后位置} = \text{当前位置} + \text{拉条百分比} \qquad (\text{可超过 100\% → 立即行动})
$$

$$
\text{推条后位置} = \max\left(0,\ \text{当前位置} - \text{推条百分比}\right)
$$

**「不被超车」的临界条件（核心口诀）**：

$$
\text{二速} > \text{一速} \times (1 - \text{拉条比例}) \quad \text{（拉条）}
\qquad
\text{二速} > \frac{\text{一速}}{1 + \text{推条比例}} \quad \text{（推条）}
$$

| 项 | 说明 |
|---|---|
| **适用边界** | 拉条/推条均**作用于当前百分比**，不是绝对距离。 |
| **反例 / 易错 1** | ⚠️ 「推条对行动条末尾的单位收益最大」——对**刚开始跑的单位推条几乎没用**。所以别对刚出手过的敌人推条。 |
| **反例 / 易错 2** | ⚠️ **拉条溢出无效**：已在 50% 位置的单位连吃两次 30% 拉条，实际只前进 50%，剩余 10% 被浪费。 |
| **反例 / 易错 3** | ⚠️ **推条最低只到 0%，无法反向超车**；同理**拉条不能把单位拉过 100% 而"多跑"**。 |
| **反例 / 易错 4** | ⚠️ 多个单位同时超 100% 时，**按原速度顺序**依次行动。 |
| **反例 / 易错 5** | ⚠️ 山兔类「攻击加成」**只对拉条后 ≥100% 的单位生效**——没被拉到终点的队友吃不到 buff。 |
| **对弈含义** | 看到「双拉条」阵容（山兔+镰鼬/久次良），要按上式计算**输出是否被拉到一速之前**；如果输出速度过低，**双拉等于白拉**。 |

## 5. 鬼火经济的数学

$$
\text{鬼火条} = 5\ \text{格};\quad
\text{第 1 / 2 / 3+ 轮回复} = 3 / 4 / 5\ \text{点};\quad
\text{鬼火上限} = 8
$$

$$
\text{对弈竞猜开局鬼火} = 4\ (\text{基础}) + 3\ (\text{火灵，多套只算一套}) + 3 \times (\text{座敷童子只数，可叠加})
$$

| 项 | 说明 |
|---|---|
| **适用边界** | 「鬼火条推进 1 格」的条件是**1 个己方单位行动回合结束**。 |
| **关键例外** | **额外回合只推进 1 格**：轮入道触发的新回合、镰鼬「人多势众」、妖琴师「余音」、八岐大蛇「不洁之力」、神乐「疾风」——**只有那个"插队者"行动结束时推 1 格**，被给予新回合的单位行动**不影响**鬼火条。 |
| **反例 / 易错** | ⚠️ 对弈竞猜**不是**「初始 3 火」（那是御魂/探索/秘闻）；对弈为 **4 火**（与斗技、结界突破一致）。 |
| **8 火上限的意义** | 大多数技能耗 3 火。上限 8 意味着**连续三个 3 火单位出手大概率断火**——这是官方刻意**压低前期节奏**的手段。 |
| **口诀** | `3 火拉条 + 3 火供火 + 2 火输出 = 8 火` = 标准启动。 |
| **对弈含义** | 界面里数不清谁是供火位，就看**谁带了火灵 / 招财猫**；再看阵容有没有座敷/辉夜姬/追月神/千姬/薰/缘结神/神无月。**缺火 = 直接判负。** |

**阵亡回火**：己方**非召唤物单位阵亡**时，己方获得 **1 点鬼火**（含八岐大蛇不洁单位的献祭）。

**失火途径**：木魅（25% 扣 1 火）、千姬潮汐印记（行动后失 3 火）、浮世青行灯掠火（扣 2 火）。

> 【官方攻略 + 大神实测】【结论性质：官方文案】

## 6. 面板口径换算提示

| 想做的事 | 该用哪套口径 | 陷阱 |
|---|---|---|
| 横向比较式神成长倾向 | A. 官网基础显示值 | 数值极小，**不能当战斗力** |
| 估算 6 星式神基础 | B. 游戏内 6 星面板 | **未含御魂/加点** |
| **对弈竞猜决策** | **C. 界面对弈面板** | **不要**用 A 或 B 去推 C；C 由**百鬼弈加点器**生成 |

**加点器每点收益**（用于判断「这个面板是否被刻意加强」）：

| 属性 | 每点 |
|---|---|
| 攻击 | +6% |
| 生命 | +5% |
| 防御 | +7% |
| 速度 | +6（固定） |
| 暴击 | +5% |
| 暴击伤害 | +7% |
| 效果命中 | +6% |
| 效果抵抗 | +8% |
| 默认自带 | 攻 +486 / 生 +2053 / 防 +104 |

标准 50 点，**实际 16–81 点不等**（实测：千姬 ≈16、鬼吞 ≈35、鸦天狗 ≈72、跳跳妹妹 ≈81、雪童子 ≈81）。

> 【玩家实测，NGA 2022 帖】**结论性质：玩家实测**。该机制在高版本是否沿用**⚠️ 待核实**，但**「对弈面板不是普通御魂堆出来的」这一结论在实战中仍然成立**（对弈界面常见御魂配不出的极限面板）。
