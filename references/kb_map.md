## 2. 已知坑位（会被反复踩，务必先比对）

1. **对弈面板 ≠ 常规面板**。对弈面板由「百鬼弈加点器」生成（`01` §2.4、`02` §6）：每点 攻+6%/生+5%/防+7%/速+6/暴+5%/爆伤+7%/命中+6%/抵抗+8%，默认自带 攻+486/生+2053/防+104；标准 50 点，实测跨度 16–81 点。**看到"御魂配不出来的极限面板"是正常的。**
2. **对弈开局 4 火**（不是 3）。火灵 +3（多套只算一套）；座敷先机 +3/只（可叠加）；上限 8。
3. **首领御魂（荒骷髅/土蜘蛛/胧车/地震鲶/蜃气楼/鬼灵歌伎）的 2 件套只在"对怪"生效** → 对弈里**基本不生效**，只能吃 8 点固有属性。
4. **针女与控制类御魂（魅妖/雪幽魂/反枕/钟灵/日女巳时/魍魉之匣）需要"对血量造成伤害"** → **打在护盾上不触发**。蚌精/磐根之佑/羽茧/蝉翼直接废掉这一整条路线。
5. **未满暴 = 暴伤归零**。按 `1 + 暴击率×(暴伤−1)` 打折，别直接乘暴伤。
6. **「唯一效果」**：多个同名式神同场只有 1 个生效（对弈会出现同阵营重复式神）。
7. **「相同」≠「相近」，且 SP 与本体同名不同人**：神无月 ≠ 石长姬；御馔津 ≠ 稻荷神御馔津；麓铭大岳丸 ≠ 大岳丸；鬼王酒吞童子 ≠ 酒吞童子；千姬 ≠ 因幡辉夜姬。
   - **⭐ SP 阶命名规则**：SP 以「**修饰前缀 + 本体名**」命名，**裸名指本体（低阶）**。**「追月神」= SR**，**「流光追月神」= SP**；同理 山兔(R)/梦寻山兔(SP)、座敷童子(R)/福悦座敷童子(SP)。
   - **两者面板、技能、定位完全不同，认错等于整局判反。** 报阵容必须写全名；只写裸名一律按本体处理并在结论里声明。
   - 查映射：`03A` §2 的「SP 变体 / sp_of」列，或 `data/shishen.json` 的 `sp_of` / `sp_forms` 字段（全 51 组已建立）。
8. **术语/别称**统一看 `01` §3 的映射表（§3.1 = SP 阶命名规则，§3.2 = 别称与误写）。
9. **官方未提供公开的 `effect_tips` 词条文案接口**（`03B` 里的 `effect_tips=53` 这类编号），编号只作交叉检索线索。
10. **⭐ `get_hero_skill` 的 `awake` 参数不是「觉醒前/后两套技能」，而是一个 diff 补丁集**：
    - `awake=1` **只返回「觉醒会改动或新增的技能」**，**不是完整技能组**；单独用它抓会**漏掉所有觉醒新增技能**（曾踩过：追月神「明月潮生」整条丢失）。
    - **正确口径：完整技能组 = `awake=0` 的键 ∪ `awake=1` 的键**；同 id 冲突时取 `awake=1` 的文案（觉醒增强版）。
    - 据此重抓后全量技能 **753 → 794**（41 个式神各补回 1 个觉醒新增技能），115 个式神的觉醒增强文案被纠正。
11. **⭐ `get_hero_attr` 对 SP 阶式神要传 `awake=0`**：SP 本体即觉醒态，传 `awake=1` **返回空**（曾导致 52 个 SP 的 6 星面板全为 null）。血量字段名是 **`maxHp`**，不是 `hp`。
12. **⭐ 首领御魂共 13 件，对弈里一律不生效**：
    - 逢魔系列 7 件：荒骷髅 / 土蜘蛛 / 胧车 / 地震鲶 / 蜃气楼 / 鬼灵歌伎 / 夜荒魂 → 2 件套**只对怪生效**。
    - **原「星痕御魂」6 件**：八咫镜 / 天羽羽斩 / 月之石 / 纺缘锤 / 稻荷穗箭 / 预言星盘 → **2026-04-15 官方已把它们「调整为首领御魂」，并明确「不再支持斗技、结界突破、道馆玩法」→ 对弈竞猜（自动斗技）同样不生效**。
    - **⚠️ 网上大量资料仍写「星痕御魂 PVP 生效 / 对弈有效」——那是 2025-03 体验服状态，2026-04-15 已作废。这是最容易被带偏的一条，务必用官方公告口径。**
    - 看到这 13 件中任何一件 → 该式神**只剩随机固有属性** ≈ 御魂错配。
13. **「只有 2 件套」不代表有 4 件套**：首领御魂本来就是 2 件套结构，别把 `05` 表里的「—」当成缺失。

      空相面灵气(366) `表里之相` · 绘世花鸟卷(367) `墨气常萦` · 须佐之男(389) `神之领域` ·
      初音未来(563) `音律起` · 心友犬神(574) `残心·雀守` · 瑶音紧那罗(579) `与世同奏` ·
      荒骷髅(585) `花吻烈魂` · 妖刀姬·绯夜猎刃(593) `霞光小调` · 思金神(601) `警醒`。

15. **⭐ 时之隙族 / 玄血 / 布都御魂 —— 光看倍率必判反**（`04 §12`，对弈高频）：
    - **时之隙**（卑弥呼 583 / 时曜泷夜叉姬 584 / 荒骷髅 585 / 平将门 592）：回合外行动，
      **不计入回合统计、不推进鬼火条、不结算回合制冷却**；主动施放时拉条 30% + 伤害 +40%（先机赋予则无拉条）。
      → **有它的对局鬼火节奏变慢，长局利好低消耗阵容**。
    - **时之缝**：印记减益，**无法被改变行动条、无法在回合外施放妖术与普攻**（反击/协战全废）。
    - **时之辉**：印记增益，场上至多 2 层、每位友方至多 1 层。
    - **玄血 / 形毁伤害**（龙珏 573）：玄血**视为生命**（不是护盾），被攻击时受到的伤害视为**形毁伤害**
      （**无视目标防御和减伤效果**）→ **纯护盾/减伤流会被绕过**，爆发型阵容更优。
    - **布都御魂**（平将门 592）：专属计数器，**每强化 3 次立即进入时之隙**；
      攻击/防守架势按「初始攻击是否 > 初始防御 × 700%」判定；防守架势受击回血（初防 500%，≤初攻 70%）。
    - **以上模拟器均不建模**，出现时必须在报告里做定性修正。
16. **⭐ 四种伤害类型必须分清**（`04 §7`）：
    - **直接伤害** = 官方口径下无特殊标注的默认类型（日常说的"普通伤害"不是官方词条）。
    - **间接伤害** → **不触发双方御魂**、目标防御为 0 时必定暴击、不被椒图/小袖分摊。
    - **真实伤害**（荒骷髅 `黄泉战旗`、针女、化鲸齿甲）→ **无视防御**，可触发双方御魂，
      **不触发伤害来源的技能/被动**（"针女般若增封印概率"是假的）。
    - **固定伤害**（平将门 `骄阳长明` 的 18%）→ 官方词条：「伤害类型的一种，**无视防御，不会暴击**」。
    - **⚠️ 真实伤害 ≠ 固定伤害**：都无视防御，但**御魂/被动/暴击行为不同**；固定伤害不吃暴伤，堆暴伤对它无效。
    - 附带：「牺牲 / 体力流失」（荒骷髅失去 30% 最大生命）**不经过「造成伤害」流程**。
17. **⭐ 官方现行「控制效果」共 16 种，不是旧口径的 9 种**（`04` §3.3–§3.4）：
    - 16 种 = 冰冻 · 沉睡 · 混乱 · 嘲讽 · 沉默 · 禁锢 · 缴械 · 变形 · 眩晕 · 挑衅 ·
      **深度冰冻 · 影缚 · 霜冻 · 拘魂 · 沉沦 · 冰眠**。
    - **后 9 种无法被驱散**（变形/眩晕/挑衅/深度冰冻/影缚/霜冻/拘魂/沉沦/冰眠），**霜冻还无法被解除**。
    - **缴械仍在「可驱散」之列**（列表第 7 位，不属于后九者）—— 别按感觉判。
    - **「无法行动」共 8 种**（冰冻/沉睡/眩晕/变形/深度冰冻/影缚/拘魂/霜冻）；
      **沉默/缴械/禁锢/混乱/嘲讽/挑衅不算**——目标仍会行动。
    - **旧口径（2018）曾把「封印/压制」算作控制效果，现已不算** —— 查旧攻略务必注意。
    - **放逐**（大岳丸等）：无法动作+不可选中+锁条+被动御魂失效+免疫伤害/治疗/增益/减益，
      **驱散解除全无效，只能庇护免疫**（`04` §5）。
    - 模拟器已按此口径建模（`CONTROL_KIND`/`HARD_CONTROLS`/`SKIP_CONTROLS`，见脚本注释）。
18. **⭐「治疗」≠「恢复」≠「吸血」**（`04` §13.3、`02` §2.12，官方蓝字词条）：
    **只有「治疗」吃暴击、受减疗影响、触发治疗相关效果**；
    **「恢复」与「吸血」不吃暴击/暴伤、不受减疗影响、不触发治疗相关效果**。
    → 对面**樱花妖 / 神乐冥蝶 / 蝎女 / 魍魉之匣**的减疗**压不住** 千姬 / 匣中少女 / 鬼王酒吞的「恢复」；
    **裁决之力的减疗同样压不住「恢复」** → 长局里「恢复系」续航比「治疗系」更耐打。
    另：**护盾与治疗都可暴击**；惠比寿鲤鱼旗不继承暴击，但吃暴击 buff 后旗子治疗仍可暴击（社区实测）。
19. **⭐「免死 / 免疫致命伤害」在扣血之前结算**（`04` §13.5、§14.2 第 11 步）：
    「能不能一波带走」= 爆发够不够打穿目标的**第 N 条命**。多数式神「**每回目 1 次**」；
    **石长姬 4 朵磐长花 = 4 次**、**百羽凤凰火至多 3 次余烬**、**蝉冰雪女用「凝结形态」顶命**；
    **茨木 `处决` 是官方写明的吸收/免疫/分摊穿透**（判断硬解手段时优先找它）。
20. **⭐「孤立」跳过分摊全族**（`04` §13.4，官方词条「最多只有 1 个敌方目标被孤立。自身无法被其他友方选中。受到的伤害无法被其他效果所分担、代替承受」）：
    → 白藏主狐影结界 / 椒图涓流 / 薙魂 / 金鱼姬 / 毗沙门天**全部失效**，**并且给不了盾、给不了回合**。
    代表：荒川之主 `吞噬`、骁浪荒川之主 `骁浪海作斩` Lv.3、赤影妖刀姬 `穷追不舍` Lv.5、歌留多。
    **替代手段：间接伤害（官方写明「无法分担」）**。
21. **⭐「失去生命」不是伤害**（`04` §13.2）：**不吃暴击、不经过护盾、不触发受击类减益/被动**
    （荒骷髅 `平氏铁壁`、夜刀神、缚骨清姬「怨」、伊邪那美「毁灭」）→ **护盾挡不住**。
22. **⭐「维持」按「来源」的回合数计算，不是目标的回合**（官方词条，`06` §2.3）：
    写「维持 2 回合」的减益，来源速度越快，**目标身上实际覆盖时长越短** → 判断控制链时长必须用来源的回合数折算。
23. **⭐ 召唤物的三条硬规则**（`06` §2.2）：① **一队只有 1 个召唤位**（惠比寿旗子 / 神乐金鱼 / 丑时之女草人 / 源博雅分身互斥）；
    ② **召唤物行动不推进鬼火条**（只有非召唤物单位回合结束才推）；
    ③ **被召唤物占位的阵亡位置无法复活** → 草人/白色小鬼是**复活流（童男/日和坊/跳跳哥哥/桃花妖）的克星**。
24. **⚠️ 未裁定冲突**：「新的自然回合 / 额外回合」是否推进鬼火条 —— **NGA 底层机制帖说「不推进」**，
    **游民星空新手攻略说「任何二次行动都增长格子」**。两说相反，本库不裁定。
    **实战做法：直接数界面左下角的鬼火格**。见 `06` §2.1、`00` §5 的 N8。

| 式神名单 | `https://g37simulator.webapp.163.com/get_heroid_list?rarity=0&page=1&per_page=1000&name=&callback=cb` |
| 式神面板（常规，觉醒后） | `.../get_hero_attr?heroid=608&awake=1&star=6&level=40&callback=cb` |
| 式神面板（SP / 不可觉醒，取 `awake=0`） | `.../get_hero_attr?heroid=395&awake=0&star=6&level=40&callback=cb` |
| 式神技能（基础集） | `.../get_hero_skill?heroid=295&awake=0&star=6&level=40&callback=cb` |
| 式神技能（觉醒 diff 补丁集，**取两次的并集**） | `.../get_hero_skill?heroid=295&awake=1&star=6&level=40&callback=cb` |
| 御魂名单 | `.../get_equip_list?pos=1&page=1&per_page=200&callback=cb`（70 个） |
| 御魂词条文案 | 萌娘百科 `https://mzh.moegirl.org.cn/阴阳师手游:<御魂名>`（逐条页面） |

要点：
- 返回是 **JSONP**，用正则剥掉 `cb(...)` 外壳再 `json.loads`。
- 需要 `Referer: https://yys.163.com/` 或 `.../shishen/` 的 UA 头。
- **⚠️ 参数别写错**：技能接口是 `star=6&level=40`，**`level=40` 后面不能再跟一个 `=`**（写成 `level=40=` 会返回 `level 格式有错`）。
- **⭐ `get_hero_skill` 的 `awake` 是 diff**：`awake=1` 只回觉醒改动/新增的技能。**完整技能组 = `awake=0` ∪ `awake=1`**，同 id 取 `awake=1` 文案。
- `awake=1` 对**不可觉醒**式神（N 阶等 15 个）返回空 → 改取 `awake=0, star=6, level=40`。
- **⭐ `get_hero_attr` 对 SP 阶式神必须传 `awake=0`**（传 1 返回空）；血量字段是 **`maxHp`**。
- 技能字段优先级：**描述取 `normaldesc`；升级效果取 `desc`（含具体数值），不要用 `simplify_desc`（是简写）**。
- 御魂页面有 **3 种版式**：`属性&效果`+`2件套属性：`、`属性`+`2件套效果:`（半角冒号）、`御魂效果`+`2件套属性：` → 解析要三种都匹配（`2|4 + 件套 + 属性|效果 + [:：]`）。
- **御魂页面并发抓取会被限流**（表现为整页读取失败），必须**串行 + 1.3s 延迟 + 重试**；抓到的纯文本**先落盘**（例如临时目录下的 `soul_text/*.txt`），再离线复解析，避免一改解析器就要重抓。
- 首领/星痕御魂的页面用 **`1件套属性：`+`2件套属性：`**，**没有 4 件套**，解析器要允许「4 件套为空」。
- 荒骷髅/土蜘蛛/蜃气楼等页面是「式神 + 首领 + 御魂」合页 → **要全局搜索首个「2件套」**，不能只看 `属性&效果` 小节。
